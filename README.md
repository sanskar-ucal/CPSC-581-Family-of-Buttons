# A Family of Buttons

CPSC 581 Group Project 1 — React app with three floating personality buttons that drift, collide (showing commonalities), reveal trait pie charts on hover, and open a detail page on click. Includes dark/light mode.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Edit teammate data

Update profiles and collision commonalities in [`src/data/people.ts`](src/data/people.ts). Swap friend avatars in `public/avatars/`.
