# A Family of Buttons

CPSC 581 Group Project 1 by Sanskar Jha, Amina Abdi, and Tanishk Batish.

Live site: https://sanskar-ucal.github.io/CPSC-581-Family-of-Buttons/

## Requirements

- Node.js 18 or newer

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build

```bash
npm run build
npm run preview
```

## Deploy

Every push to `main` builds and deploys the site to GitHub Pages through GitHub Actions.

## Project structure

- `src/data/people.ts`: names, bios, hobbies, songs, and photos for each person
- `src/components/`: buttons, carousel, music disc, and backgrounds
- `src/pages/`: home page and profile page
- `public/`: photos, avatars, album covers, and music
